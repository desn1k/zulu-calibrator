# Локальный запуск (без входа)

Пока нет входа по логину (PR-4), калькулятор запускается **только на своём компьютере** — адрес
`127.0.0.1`, в сеть не открывать.

## Что нужно

- Python 3.12 (подойдёт и 3.13), Git.
- Репозиторий: `git clone https://github.com/desn1k/zulu-calibrator.git`, затем `cd zulu-calibrator`.

## Запуск

Windows (PowerShell):

```powershell
powershell -ExecutionPolicy Bypass -File scripts\run_local.ps1
```

Если команда `py -3.12` не находит Python, укажите свой: `... run_local.ps1 -Python python`.

Linux / macOS:

```sh
sh scripts/run_local.sh
```

Скрипт сам создаёт `.venv`, ставит зависимости, готовит базу `data/local.db` и запускает сервер.
Откройте **http://127.0.0.1:8000/**. Остановить — `Ctrl+C`. База остаётся в `data/local.db`
(история расчётов сохраняется между запусками).

## Порядок работы

1. **Новый расчёт ЦТП** → вставить карточку ЦТП из Zulu (строки «поле — значение») и выбрать выгрузку
   потребителей (xlsx или csv с заголовками). Name, Bld, Adres, FIAS_Adress, FIAS_ID, UUTE_Name
   удаляются в браузере до отправки. Старый JSON калькулятора — в разделе «Файл старого калькулятора».
2. **Факт ЦТП** — заполнен из блоков приборов карточки (_TS ввод, _OT отопление, _GVS ГВС, _SV
   вентиляция); t источника — вручную. Давления в м вод. ст. (или кгс/см², пересчёт ×10).
3. **Проверка приборов** — проверки 1–11 с легендой статусов; правки факта потребителей по Sys (блок
   прибора, значение, «не доверять»); доли многовводовых домов; приборы домов, нарисованные узлами
   учёта, — вручную (до выгрузки сети). Правки сохраняются при каждой новой выгрузке.
4. **Шаги 1–5** — таблица «ввести», «Копировать» (Sys / поле / значение через табуляцию) и SQL для
   Zulu: пакетом («;» после каждой команды, кроме последней) или «по одной» (без «;»), кнопка
   «Скопировать SQL», имя слоя — настройка расчёта. После правок в Zulu — поверочный расчёт и
   «Загрузить свежую выгрузку» (карточку ЦТП можно не вставлять — возьмётся предыдущая).
   Дальше — когда критерии сошлись, или «Принять с отклонением» с комментарием.
5. **Итог** — модель / факт. **История ЦТП** → «Продолжить» открывает текущий шаг.

Числа выводятся с десятичной запятой.
